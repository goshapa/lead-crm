# Lead CRM

Мини-CRM в духе amoCRM для отдела продаж + парсер Яндекс.Карт, который находит
компании без сайта и складывает их в воронку.

- **Сделки** — канбан-воронка с перетаскиванием и список с массовыми действиями
- **Карточка сделки** — поля, лента событий, примечания, задачи
- **Задачи** — просроченные / сегодня / завтра / позже
- **Аналитика** — воронка, конверсия, показатели менеджеров
- **Парсер** — поиск компаний на Яндекс.Картах (только локально)
- **Настройки** — этапы воронки, пользователи и роли

## Как устроено

| Где | Что работает | База |
|---|---|---|
| Vercel | CRM для всей команды | Postgres (Neon) из `DATABASE_URL` |
| Компьютер (`python app.py`) | CRM + парсер (нужен Microsoft Edge) | тот же Postgres из `.env`, либо локальный `leads.db` |

Парсер в облаке не работает: Яндекс.Карты блокируют headless-браузеры, поэтому
нужно настоящее окно Edge. Локальная версия с тем же `DATABASE_URL` пишет
найденные компании прямо в облачную базу.

## Локальный запуск

```bash
pip install -r requirements-local.txt
python app.py
```

Откройте http://127.0.0.1:5000 (или запустите `start.bat`). При первом запуске
сайт предложит создать администратора.

Чтобы работать с облачной базой, скопируйте `.env.example` в `.env` и вставьте
строку подключения `DATABASE_URL`.

## Деплой на Vercel

1. Подключите к проекту Postgres (Vercel → Storage → Neon) — переменная `DATABASE_URL` появится сама.
2. Задайте `SECRET_KEY` (случайная строка) в Environment Variables.
3. `vercel --prod`.
4. Администратора создайте в локальной версии с тем же `DATABASE_URL` — в облаке
   форма первого запуска отключена, чтобы админом не стал случайный посетитель.

Часовой пояс задаётся `APP_TZ` (по умолчанию `Asia/Tashkent`), валюта — константой
`CURRENCY` в `static/app.js`.
